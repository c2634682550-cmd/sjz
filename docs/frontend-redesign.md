# 前端配色与可用性重做

## 一、配色：从「开发者冷灰蓝」到「游戏风青黑」

### 上一版为什么不行

用的是 GitHub Primer dark，色值本身没问题（有对比度保证、有变量体系），
但那是**给开发者看网页的配色**：冷灰蓝、低饱和。用户原话「太烂了」、
「给玩家看太工程了」。

### 这一版的来源

不是凭「军事题材」猜一个军绿色，而是**从三角洲行动的实际界面采样**：

| 用途 | 色值 | 来源 |
|---|---|---|
| 窗口底 | `#161C21` | 交易行截图采样 |
| 卡片 | `#1F272D` | 交易行截图采样（`#1F272D` / `#212A2E` 之间） |
| 高亮行 | `#232A34` | 设置菜单截图采样 |
| hover | `#2D3B44` | 交易行右下角采样 |
| **主强调** | **`#0FF796`** | 三角洲国际官网计算样式 |
| 次强调 | `#FF6C00` | 同上 |
| 正文 | `#E7E7E7` | 同上（官网标题色） |
| 次要 | `#B8B8B8` | 同上（官网表单文字色） |
| 弱 | `#A6A6A6` | 同上（官网次级文字色） |

**要清楚这些证据的强度差别**：

- 截图采样值只能证明「这张图这个位置的像素」，不是客户端 UI token；
  压缩、透明度、场景背景、版本都会影响。取得的是 2024 年的旧图。
- 官网计算样式是**网页实现值**，不是客户端设计规范。
- **没有查到三角洲客户端公开的完整色板。**

所以这套配色的准确说法是：**「向三角洲靠的青黑 + 荧光绿战术风」，
不是「三角洲官方色板」。** 长这样是刻意的，不假装有官方依据。

### 语义色是借用+重新映射

| 用途 | 色值 | 来源 |
|---|---|---|
| 成功 | `#95AF7D` | BF4 社区采样（Squad Friendly） |
| 警告 | `#FFB500` | BF4 社区采样（Helicopter HUD 琥珀） |
| 危险 | `#FE4E1D` | Apex 主菜单选中条采样 |
| 信息 | `#77B0CA` | BF4 社区采样（Party Member） |

**这些不是那两款游戏的官方错误色 token**，是我们把它们的 HUD 颜色
重新映射成工具的状态色。

### 对比度实测（自己算的，不是抄调研的）

对窗口底 `#161C21`：

| 用途 | 色值 | 对比度 | AA 正文 (4.5:1) |
|---|---|---|---|
| 正文 | `#E7E7E7` | 13.89:1 | ✓ |
| 次要 | `#B8B8B8` | 8.66:1 | ✓ |
| 弱 | `#A6A6A6` | 7.06:1 | ✓ |
| 主强调 | `#0FF796` | 12.08:1 | ✓ |
| 成功 | `#95AF7D` | 7.12:1 | ✓ |
| 警告 | `#FFB500` | 9.71:1 | ✓ |
| 危险 | `#FE4E1D` | 5.17:1 | ✓ |
| 信息 | `#77B0CA` | 7.24:1 | ✓ |

### 两个必须记住的坑

**1. 荧光绿上不能放白字。**

| 荧光绿 `#0FF796` 上的文字 | 对比度 |
|---|---|
| 白色 | **1.42:1 ← 完全看不见** |
| 深色 `#161C21` | 12.08:1 ✓ |

主按钮必须用 `--accent-ink`（深色）。同理危险橙 `#FE4E1D` 上白字只有
3.32:1，也得用深色。

**2. 危险色的余量很小。**

`#FE4E1D` 对窗口底是 5.17:1，但**对卡片底 `#1F272D` 只剩 4.56:1** ——
刚过线。所以：

- 不要给危险色加透明度
- 不要随手调亮卡片底色
- 改动后必须重算，不能凭感觉

这两条都写在 CSS 注释里，放在会被看到的地方。

## 二、可用性：把技术词换成玩家的话

### 术语审计

101 条面向用户的文案，逐条判定。要害是**区分两类词**：

| 保留（游戏内真实说法，玩家懂） | 替换（我们自己的技术词，玩家不懂） |
|---|---|
| 砖皮、极品、优品、成色 A/S/B、赛季 | 模板、相关度、阈值、触发方式、状态机、布防、整队、Tesseract |

### 具体替换

| 原来 | 现在 | 为什么 |
|---|---|---|
| 把框内画面存成模板 | **记住它长什么样** | 「模板」是印刷术语 |
| 匹配阈值 0.85 | **多像才算数 85%** | 百分比比小数直观 |
| 当前相关度 0.000 | **现在像不像 29%** + 绿/黄变色 | 数字要能自己判断好不好 |
| 触发方式 / 等按钮消失 | **什么时候开抢 / 按钮变了就抢** | 「触发」是程序概念 |
| 状态机 idle | *（删除）* | 玩家不需要知道状态机 |
| 检测频率 0 Hz | *（删除）* | 同上 |
| 左上角急停 | **鼠标甩左上角急停** | 说清动作 |
| 到点前 20 秒自动布防 | 到点前自动开始等 | 「布防」是军事词，费解 |
| 演练整队 / 实战开抢整队 | 演练 / 实战开抢 | 「整队」是生造的 |
| 中文用 Windows 自带 OCR，不用装 Tesseract | *（删除）* | 玩家不需要知道底层 |
| 框选区域 | **教它认按钮** | 说清目的而不是动作 |

### 信息分层

**向导式**（框选页改名为「教它认按钮」）：

```
① 框住【购买】按钮  →  记住它长什么样
② 让它认得商品名（可选）
③ 什么时候开抢
```

三步有编号、按顺序排、每步一句白话说明。

**高级参数折叠**（`<details>`）：

多像才算数 / 每秒点几下 / 确认按钮点几下 / 等弹窗最多几秒 / 急停开关
—— 默认值已经能用，不该占据主流程。

**关键信息提到前面**：「现在像不像」从参数区提到第 3 步之前 ——
它其实是用户验证「框得对不对」的唯一手段，不该埋在高级设置里。

### 布局：向导不该要滚动

框选页改成**左右并排**：

```
┌──────────────────┬─────────────┐
│                  │ ① 框住购买  │
│   实时预览        │ ② 认商品名  │
│   （拖框用）      │ ③ 何时开抢  │
│                  │ 现在像不像  │
└──────────────────┴─────────────┘
```

实测预览容器从 240px 变成 **664px**，三个步骤一屏放完。

## 三、素材：用了官方素材，以及它的实际状态

**界面上现在有两处三角洲行动的官方素材**，都是从官方 CDN 取的：

| 文件 | 来源 | 原始尺寸 | 落到 `web/assets/` |
|---|---|---|---|
| `df-logo.png` | `www.playdeltaforce.com/favicon.png` | 150×150 | 裁 bbox 后 96×96 |
| `df-bg.jpg` | `web.df.garena.com/…/en/pc/bg_01.jpg` | 3840×2160 | 缩到 1600×900、压暗 |

顶栏只放**三角标志**，不放带 `DELTA FORCE` 字标的 `top_logo_01.png`——
界面上已经是中文，再混一行英文会打架。

### 授权状态：不声称有授权

**没有找到允许把三角洲行动官方素材嵌入第三方软件并分发的公开许可。**

依据是《腾讯游戏许可及服务协议》7.1 条：未经腾讯事先书面同意，
「不得……进行商业性使用或通过信息网络传播腾讯游戏内容」。
「免费、开源、注明出处」**不能替代授权**。

同类作品大量存在是事实，但那说明的是权利人的容忍度，不是授权。

**这是项目所有者知情并接受的风险决定**（非商业用途）。本文件如实记录，
不构成授权声明，也不替代法律意见。要移除的话，删掉 `web/assets/` 下两个文件
并回退 `web/index.html` 里的三处引用即可，界面会自然回落成纯配色主题。

### 配色：不受版权保护，因此照用

界面配色**不是**从官方素材里取的像素，而是从官方站点的**计算样式**读出来的色值
（`#0FF796` / `#FF6C00` / `#E7E7E7` / `#A6A6A6`）。色号本身不构成受保护的作品。

导航图标是**自己画的**：用官方三角标志的几何（正三角 + 内嵌小三角）套上功能符号，
不是官方图标文件。这样视觉语言一致，又不用官方资源。
替代方案见下（若要全部换成开源图标）：

| 来源 | 授权 | 用途 |
|---|---|---|
| [Phosphor](https://github.com/phosphor-icons/core) | MIT | 导航、状态、操作图标 |
| [game-icons.net](https://game-icons.net/about.html) | CC BY 3.0 | 准星、盾牌、雷达等战术感图标 |

## 四、静态资源的服务端改动

前端引用的 `/assets/*` 原来一律 404 —— `do_GET` 只硬编码了 `/` 和 `/index.html`，
没有通用静态分支。表现是 **logo 破图、背景不显示，而且控制台不报任何错**。

新增 `Handler._asset()`，两道约束：

1. **后缀白名单**（png/jpg/webp/svg/ico），非图片不服务；
2. **`normpath` 后必须仍在 `web/assets/` 内**，挡 `../` 穿越。

服务绑在 127.0.0.1，但浏览器里任何一个页面都能往它发请求，所以穿越必须挡。

**测试上踩过两次坑，都是「断言永真」**，记在这里免得重犯：

- 穿越用例最初用 `../index.html`、`../../core/server.py`——这些后缀不在白名单，
  被**后缀白名单**拦住，`normpath` 守卫根本没被触发；把守卫删掉测试照样过。
  改用 `../../_shots/<真实PNG>`（后缀合法 + 目标存在）才有区分力。
- 白名单用例最初用 `assets/x.txt`、`assets/config.json`——这些文件**不存在**，
  是「文件不存在」返回的 404。改成真的往 `assets/` 放一个 `.txt` 再测。

另外，`urllib` 会在发请求前把 `assets/../x` 规范化成 `/x`，请求根本到不了
路由。测试改用**原始 socket 写请求行**（`_get_raw`）。

三个守卫现在都验证过「把代码改坏 → 测试失败」。

**注意**：`PrintWindow` **抓不到 WebView2 里的 MJPEG 层**，
所以窗口截图里预览区总是黑的 —— 那是截图工具的限制，
不是渲染问题。判断预览是否正常只能用 canvas 读像素。

pywebview 的 `Window` **没有截图 API**（只有 `evaluate_js` 等），
所以顶栏截图是让页面用 `drawImage` + CSS 色值把关键区域重绘到 canvas 再落盘的。
重绘只覆盖 canvas 能画的元素，HTML 按钮/pill 不会出现——那是重绘的局限。
